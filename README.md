# Microstrip Patch Antenna Design Using CST Studio Suite

## 📡 Project Overview

This repository showcases my **Microstrip Patch Antenna Design** developed using CST Studio Suite as part of my hands-on learning in RF and Antenna Engineering.

The project focuses on antenna geometry design, electromagnetic simulation, and visualization of antenna characteristics using computer-aided simulation tools.

## 🎯 Objectives

* Design a microstrip patch antenna using CST Studio Suite.
* Understand the fundamentals of RF and microwave antenna design.
* Explore antenna performance through electromagnetic simulation.
* Visualize the antenna structure and simulation results.
* Gain practical experience in antenna engineering and simulation workflows.

## 🛠️ Tools and Technologies

* **Software:** CST Studio Suite
* **Domain:** RF and Microwave Engineering
* **Design Type:** Microstrip Patch Antenna
* **Method:** Electromagnetic Simulation
